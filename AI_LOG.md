# AI Usage Log

## Tools Used

- ChatGPT (OpenAI)
- Figma AI / Figma Make

## How AI Was Used

AI was used as a supplementary learning, planning, design, debugging, and quality-assurance tool during Semester Project 2.

The assistance included:

- Breaking the assignment brief into smaller development tickets and acceptance criteria
- Supporting project planning and prioritisation throughout the development period
- Reviewing proposed application architecture and reusable component structure
- Assisting with debugging JavaScript, API integration, validation, and responsive layout issues
- Explaining Git commands, branching, pull requests, and deployment behaviour
- Reviewing API requests, session handling, authentication flows, and error handling
- Assisting with manual testing strategies and interpretation of browser Console and Network results
- Reviewing accessibility, responsive behaviour, Lighthouse findings, and final QA requirements
- Reviewing code against the assignment brief and identifying remaining requirements
- Assisting with documentation and reflection on the development process
- Using Figma AI to generate an initial high-fidelity design direction from the assignment brief
- Iteratively refining the AI-assisted Figma design to match the intended visual concept and application requirements

## Development Responsibility

All implementation, testing, Git operations, API integration, debugging decisions, and final design decisions were performed and verified by the student.

AI-generated suggestions were treated as proposals rather than automatically applied solutions. Suggestions were reviewed against the assignment requirements, adjusted when necessary, and manually tested before being incorporated into the project.

AI assistance did not replace manual testing or verification. Features were tested in the browser using development tools, responsive testing, Lighthouse, ESLint, Prettier, production builds, and manual acceptance-criteria testing.

## Notes

AI was particularly useful for maintaining structure during a relatively large project. ChatGPT was used throughout development to help break complex requirements into manageable tasks and to reason through problems before changes were made.

Figma AI was used during the design phase by providing the assignment brief as an initial prompt and then iteratively refining the generated design. The resulting prototype was further adapted during implementation based on responsive testing, accessibility requirements, and technical constraints.

Several AI suggestions were modified after testing showed that a different implementation was more appropriate. AI output was therefore used as development support rather than as a substitute for understanding, implementation, or verification.
